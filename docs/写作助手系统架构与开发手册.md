# AI智能写作助手系统架构与开发手册

---

## 一、系统简介

**AI智能写作助手**是一款面向长文本创作、学术论文起草、企事业单位公文撰写、自媒体文案策划及各类专业文章写作的智能化辅助工具。系统充分利用**提示词工程 (Prompt Engineering)** 与**上下文生命周期管理 (Context Management)**，实现了从主题构思、结构化大纲生成、逐章节沉浸式写作，到多维度润色和标准 Markdown 成果物导出的一站式工作流。

---

## 二、系统架构与模块划分

系统遵循模块化、高内聚、低耦合的设计原则，核心代码组织如下：

```
AI问答助手/
│
├── app.py                       # Streamlit 用户界面与交互主程序
├── requirements.txt             # 项目运行依赖声明
├── run.bat                      # Windows 一键启动脚本
│
├── core/                        # 核心引擎包
│   ├── __init__.py
│   ├── config.py                # 环境变量与API配置管理（自动装载本地密钥）
│   ├── prompt_templates.py      # 分层提示词工程模版库
│   ├── context_manager.py       # 上下文生命周期与多轮对话记忆管理
│   ├── llm_service.py           # 大语言模型接口服务（流式响应与错误处理）
│   └── markdown_builder.py      # Markdown构建器（Front Matter、目录、自动落盘）
│
├── docs/                        # 设计规范与技术文档
│   ├── 提示词工程与上下文管理设计规范.md
│   └── 写作助手系统架构与开发手册.md
│
└── result/                      # 成果输出目录（自动归档生成的 .md 文件）
```

## 三、核心功能工作台说明

1. **✍️ 智能写作工坊 (Long-form Writing Studio)**：
   - **大纲构建器 (Outline Builder)**：输入主题、文体（学术论文/技术文档/商业策划/公文报告/爆款网文等）、读者定位及预期篇幅，AI 运用思维链（CoT）生成多级 Markdown 大纲。
   - **交互式微调 (Interactive Outline Tuning)**：用户可直接在线编辑与审阅大纲，调整各章节重点。
   - **章节串联扩写 (Contextual Chapter Expansion)**：系统结合“全局主旨 + 前章摘要 + 当前章节重点 + 后章预告”，逐章流式生成详实正文，并自动汇编为完整 Markdown。

2. **🛠️ 文本精炼与润色台 (Text Polish & Refinement)**：
   - 支持【学术规范化】、【商务公文规范】、【错别字与语病校对】、【扩写详述】、【精炼摘要】、【语气转换】等 6 大核心优化模式。
   - 具备修改点说明与前后对比功能。

3. **💬 交互式灵感对话 (Brainstorm & Chat)**：
   - 围绕写作灵感、结构构思、素材搜集与论据推敲进行多轮问答，上下文记忆无缝流转，生成内容自动采用规范 Markdown。

4. **📂 成果库与 MD 预览器 (Document Manager)**：
   - 自动扫描并展示 `result/` 目录中的所有已生成 Markdown 成果。
   - 具备源码/渲染视图切换、字数统计、下载 `.md` 文件及一键复制功能。

## 四、核心接口与数据流

### 1. 大模型通信流 (LLM Communication)
- 兼容 OpenAI 标准 API 规范，默认原生支持 **DeepSeek**（包括 `deepseek-chat` 与 `deepseek-reasoner` 深度思考模型）。
- 支持 SSE 流式传输（Server-Sent Events），实现实时打字机效果。

### 2. Markdown 构建流 (Markdown Assembly)
- 每个生成的作品包含规范的 YAML Front Matter（标题、生成时间、作者、分类、字数等）。
- 汇编完毕后自动生成独立文件落盘至 `result/`，文件名为时间戳与主题的组合。

## 五、环境要求与部署运行

### 1. 运行环境
- Python 3.10+
- 依赖项：`streamlit`, `openai`, `requests`

### 2. 一键启动
在项目根目录下双击运行 `run.bat`，或在命令行中执行：
```bash
.\venv\Scripts\streamlit.exe run app.py
```
启动后，系统将自动在默认浏览器中打开写作助手交互界面（通常为 `http://localhost:8501`）。
